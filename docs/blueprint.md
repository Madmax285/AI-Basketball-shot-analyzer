# **App Name**: VolunteerBridge

## Core Features:

- Volunteer Registration: Allow volunteers to register their details including name, skills (multi-select), location, and availability (hours per week), storing this data for matching.
- Mission Posting: Enable NGOs to post new mission opportunities with details like title, description, required skills, location, urgency, and number of volunteers needed, saving this information.
- AI-Powered Volunteer Matching: Calculate and rank volunteers for a mission based on weighted criteria including skill alignment, location proximity, availability, and mission urgency using an AI engine.
- Explainable Match Tool: Provide concise, AI-generated explanations for each matched volunteer, detailing the reasons behind the match, such as 'Matched because skills align, nearby location, and high availability.'
- Dashboard Overview: Display key metrics including total registered volunteers, total active missions, and a count of completed missions using simple data visualizations.
- Intuitive Navigation: Implement a clear sidebar navigation to allow users to easily switch between the Volunteer Registration, Mission Posting, View Matches, and Dashboard pages.

## Style Guidelines:

- A light color scheme to convey clarity and approachability. The primary color will be a fresh, muted blue-green (#33C2CC) to symbolize trust and collaboration. The background will be a very light desaturated version of this hue (#ECF5F6), creating a serene canvas. An accent color in a complementary minty green (#5FE6BB) will highlight calls to action and important elements, offering a pleasant contrast.
- Headline and body font: 'Inter' (sans-serif), chosen for its modern, clean, and objective aesthetic, ensuring high legibility across all content types within the platform.
- Utilize modern, outline-style icons for navigation and actions, maintaining a clean and professional look that supports clear communication without visual clutter.
- A responsive two-column layout with a persistent left-hand sidebar for primary navigation and the main content area occupying the rest of the screen, ensuring a consistent user experience across devices.
- Subtle, quick transition animations for page navigation and form submissions, providing visual feedback and enhancing the feeling of responsiveness without distracting the user.
